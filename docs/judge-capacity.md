# 審査用の生成枠

2026-10-18、全体の生成予約上限を25セット・$375へ増やす承認を受けた。
使用済み3セットを含む上限であり、変更時点で残りは22セット。
1セットは音楽60秒と映像12秒×6本、予約上限$15。
実請求額は予約額とは異なる。本変更ではfalの購入や自動補充設定を操作しない。
実利用に伴う請求は利用アカウントの課金設定に従う。追加請求を含む承認後に本番枠へ適用する。

1ルーム最大5セット、全体最大100ルーム、本日23:59:59日本時間までの条件を維持する。
生成は全ルーム共通の先着枠であり、ルーム作成だけでは5セット分を取り置かない。

`cloud/cloudflare/generation-capacity-migration.sql`はイベント表の許容範囲だけを広げる。
既存のイベント値・ルーム・生成記録・費用予約は維持する。
適用時は同じD1トランザクションで実行し、参照関係の検査に成功したことを確認する。
イベントの実際の予算変更は、承認された`judge-production`の`maximum_cents`だけを37500へ更新する。

参照: [Cloudflare D1の参照関係と移行](https://developers.cloudflare.com/d1/sql-api/foreign-keys/)。
