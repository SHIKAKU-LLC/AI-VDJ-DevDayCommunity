# 短文と任意の画像から演出を作る

利用者は短いプロンプトだけで音楽60秒と映像12秒×6本を生成できる。画像は任意であり、画像なしの投稿では画像解析を呼ばない。
画像を添付したときだけ、見える特徴を読み取り、既存のEDM・サイケトランスの方向性に合う演出指示へ組み込む。
画面操作と合成データによる連携を検証した。画像機能は既定では無効とし、承認された検証用Workerだけで実生成を確認する。本番への反映は別途行う。

## 画像を添付した場合

1. ブラウザでJPEG・PNG・WebPを読み込み、最大1024px・2MiBのPNGに変換する。元画像は8MiBまで。元のファイル名や位置情報は送らない。
2. サーバーでもPNGの構造、寸法、チェックサムを確認し、付随する文字情報を削除する。画像はルーム単位の非公開R2へ保存する。
3. 投稿者の権限・投稿の識別子・文章のハッシュと画像を結び付ける。別の投稿者や別の文章には流用しない。画像の追加・変更は文章の投稿前までとする。
4. 生成枠を確保してから、Workers AIのMoondream 3.1で主な被写体・画風・残す特徴・色を読み取る。通常は1回。画像中の文章は指示として扱わない。実在人物の名前や機微な属性は推測しない。
5. 構造化された結果を検証し、共通のVJ指示に組み込む。6場面で登場、周回、色と形のトンネル、分解と再構成、細部、全体への引きを使い分ける。
6. H3 Maxのreference-to-videoへ、生成した指示と期限付きの画像参照を渡す。写真・イラスト・ドット絵の特徴を保つよう指示し、背景の文字や値札を除外する。

顔や細部の完全一致、背景除去の品質、生成時間は実生成で確認する。画像を読む処理が失敗したときに、画像を無視した動画を勝手に生成しない。

## 境界と費用

- 原本・生成素材・画像の取得用URL・APIキーをGitへ追加しない。画像は公開素材集へ登録しない。
- 画像の受付は既存のルーム認証と有効期限に従う。1ルーム30画像・1投稿者6画像までで、生成自体は従来の1ルーム5セット・イベント共通予算の制限を維持する。
- 画像解析は生成枠を確保した投稿にだけ実行する。実行中の印を先に保存し、応答を失っても自動で再購入しない。
- 返答は解析前に非公開のDurable Objectへ一時保存する。形式の修正時は同じ返答を使い、別の推論を買わない。共有するD1の進行状況やブラウザには生の返答を出さず、正常に解析できたら一時保存を外す。旧版で返答を保存できなかった場合の明示的な再試行は、合計3回までに制限する。
- JSONの前後に付いた単一の囲みだけを除去し、構造・文字数・項目を検査する。余分な指示やURLを受け入れない。画面へ出す演出説明は日本語にする。
- 指示作成に使うモデル名と映像モデルはコードで固定する。AIの応答からURL・実行先・予算・権限を変更しない。
- Workers AIは`AI`の接続を使い、利用者にキーを入力させない。`VDJ_IMAGE_DIRECTION_ENABLED=true`で配備するときだけ接続と受付を有効にする。
- 2026-10-18の参照映像モデルの基本単価は1秒$0.05。解像度や入力による料金は実行前に確認する。画像解析は別途Workers AIの従量料金で、Moondreamの公表単価は入力100万トークン$0.30・出力100万トークン$1.00。解析の出力は768トークンまでに制限する。
- 1セットの予約上限$15と既存のイベント予算は変更しない。配備・新しい有料処理の確認は別途行う。

## 検証

合成PNGと模擬APIを使い、画像なしの従来動作、投稿者の分離、文章との照合、サイズ超過、文字情報の除去、圧縮データの長さ、AI応答の検証、重複防止、6場面の指示を確認した。
ブラウザの模擬環境では、オーナーと参加者の短文投稿、画像の選択・取消・送信、390px幅の表示と再読み込みを確認した。
ローカルの画面確認と、Cloudflare上での実生成・実再生は分けて記録する。

### 2026-10-18 検証用環境での実生成

- 検証用Worker `ai-vdj-devdaycommunity-staging` のみで画像機能を有効化した。専用イベント `judge-image-smoke` は1ルーム・予約上限$15・同日23:59:59（日本時間）まで。本番のイベント枠は変更していない。
- 人形の参考画像1枚と「ネオンのダンスフロアで、ベースに乗って踊る」という短文から、音楽60秒とH3 Maxの1080P映像12秒×6本を実生成した。全7素材が検査を通過した。
- 最初の実行でWorkers AIの返答形式の違いを検出し、有料の音楽・映像生成前に停止した。返答の正規化と非公開の一時保存を追加し、同じ予約1件で復旧した。最終的な音楽・映像の送信は7件のみで、再購入はない。
- 音楽は送信から約16秒、再生開始に必要な映像2本は約69秒、映像6本すべては約178秒で検査が完了した。この数値には最初の画像解析の修正時間を含めない。
- ブラウザの全画面で、眼鏡・巻き髪・人形の造形を保ち、背景の値札や文字を除外した映像を確認した。約112秒時点で復号失敗0・映像切替失敗0、最大連続無音は約0.023ms。1曲の継ぎ目を越えて再生を継続した。異なる新曲同士の切替を追加生成で試したものではない。
- この検証は参考画像1枚のみ。他の画風や別の人物に対する一致率を保証しない。実請求額は未確定。PRのマージと本番の画像機能の有効化は未実施。
