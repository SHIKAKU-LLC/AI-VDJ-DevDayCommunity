# 使い方と操作ガイド

[READMEへ戻る](../README.md)

## 審査・体験用の使い方

1. **ルームを作る**

   [本番サービス](https://ai-vdj-devdaycommunity.hapx2yuki.workers.dev/room)を開き、「ルームを開く」を押します。その端末がオーナーの再生画面になります。
2. **参加者を招待する**

   「みんなを招待・受付設定」を開き、QRコードを読み取るか、「URLをコピー」で参加用URLを共有します。参加者は呼ばれたい名前を入力し、「参加する」を押します。
3. **プロンプトと、任意で画像を投稿する**

   「ネオンの猫が踊る」「宇宙を走る重低音」など、短い言葉を入力します。画像を使う場合だけ「画像を添付」から添付し、「送る」を押します。画像なしでも生成できます。オーナー自身も「生成する」から投稿できるため、1人でも試せます。
4. **生成を待つ**

   投稿を受け付けると、サーバーが音楽12秒と映像12秒を各1本生成します。「生成状況」で進み具合と採用回数を確認できます。オーナー画面を閉じても生成は続きます。生成時間は外部サービスの混雑状況で変わります。
5. **音楽と映像を大画面で楽しむ**

   準備完了後、オーナー画面で「再生する」→四隅の拡大アイコンを押します。投稿の完成前はプリセットを流し、完成後は次の12秒の区切りから投稿の音楽・映像へ切り替わります。

### おすすめの試し方

- **言葉だけで試す**：「宇宙を走る重低音」で、共通のDJ・VJ演出と投稿したテーマの組み合わせを確認します。
- **画像を添えて試す**：キャラクターなどの画像に「ネオンのステージで踊る」と添え、被写体の特徴と動きが映像へどう反映されるかを見ます。
- **2人以上で試す**：1台を再生画面、もう1台を参加者画面にして、投稿から生成・演出への追加までを体験します。
- **再生を続けて試す**：曲の切り替え、複数の映像、生成待ちの間の演出を通して確認します。

繰り返し投稿できます。1ルーム最大100投稿で、イベント全体の残予算にも上限があります。再生中はオーナーのタブを開いたままにしてください。
全画面の解除は**Esc**、再生の停止は「停止」です。
生成費用は運営側が負担し、参加者への請求はありません。審査用の受付期間・生成枠には上限があります。

## 操作卓の使い方

- **再生と停止**：音楽と映像の準備ができたら「再生する」を押します。「停止」で止められます。
- **大画面**：四隅の拡大アイコン、または `F` キーで全画面を切り替えます。解除は `Esc`。操作部分はポインターを動かすか、キーボードでフォーカスすると表示されます。
- **出力音量**：フェーダーで0 dB〜−60 dB（下端は無音）に調整できます。矢印キーでも操作でき、ダブルクリックで0 dBに戻ります。スピーカーボタンのミュート中も曲と映像は進みます。
- **出力メーター**：音量調整後の左右の実信号を表示します。
- **明暗**：右上の切り替えからダーク・ライト・端末設定を選べます。初期表示はダークです。再生や入力内容は保たれます。
- **スマートフォン**：「映像」「投稿」「生成状況」のタブで切り替えます。表示を切り替えても再生は止まりません。参加者には投稿と生成状況が表示されます。
- **招待と受付**：「みんなを招待・受付設定」で参加用QRコードと投稿の受付を操作できます。生成は投稿の受理後に自動で始まります。

操作画面は[audiocn-dsの公式規則](https://audiocn-ds.vercel.app/docs/ai/design-rules)に沿い、Stone配色と機材の操作卓を思わせる部品で統一しています。映像作品の表現はそのままに、投稿・生成・再生の状態を見分けやすくしています。[利用部品とライセンス](../room-web/console/THIRD_PARTY.md)
