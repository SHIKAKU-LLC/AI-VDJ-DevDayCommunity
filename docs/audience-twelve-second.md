# 12秒投稿・公平な再生キュー

## 実装

1投稿から12秒の音楽・12秒の映像を生成する。画像は任意。
受付・再生順はAudienceRoom、各投稿の進行はGenerationJobで管理する。
30件を並行して開始し、falには音楽・映像の計60依頼を投入できる。
fal側の実行枠が30なら、同時に処理するのは最大30依頼で、残りはfalの待機列に入る。

受付の応答までに投稿と処理待ちを永続化する。応答が途切れても同じnonceで取り戻せる。
料金照会はルーム内で30秒共有し、30人の同時投稿による照会の集中を避ける。
有料生成の送信が不明になった場合は自動で再送しない。

両方の素材の品質検査が終わり、ブラウザが読み込めた投稿だけを選ぶ。
採用回数、完成時刻、投稿IDの順で比較する。採用回数は再生開始の確認で一度だけ増やす。
再生権の期限は15秒、更新は5秒ごと。接続を確認できない端末は停止し、二重に進行しない。

プリセットは運営が指定した映像と、新規12秒音楽の組み合わせとする。
3分のデモ用には15組を準備する。最大38組まで対応し、既存映像は保持する。
一巡するまで再利用せず、次の巡回でも直前の素材は避ける。
通常の参加者の画像・素材を共通ライブラリへ取り込まない。

## 配備した変更

- D1: `audience-migration.sql`。投稿・操作の分離、待機音楽と承認済み生成バッチの表、$4の一括予約。
- Durable Objects: AudienceRoom、GenerationJob、PresetBatchを追加。既存のGenerationRoomは維持。
- Containers: 各環境最大4台、standard-2、未使用3分で停止。検査前に枠を予約する。
- 既存予約と素材を保持。新規投稿は1件$2.50、1ルーム100投稿、総予約上限$375。
- 待機音楽はデモ用15本、承認済み上限$4。画像なし・画像あり各1件の実生成確認は上限$5。
- 受付期限は2026年10月18日23:59:59日本時間を維持する。

D1変更・クラウド設定・配備・実生成は、対象差分と費用を提示し、承認を受けて実施した。
購入は運営者本人が行い、APIキーは画面・Git・ログに出さない。
