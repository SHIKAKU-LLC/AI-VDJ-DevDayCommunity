# AI VDJ — 観客のひとことが、次の12秒になる。

**QRから参加して送った言葉や画像が、会場の音楽と映像になる参加型DJ・VJサービスです。**
勉強会やコミュニティイベントで、見ている人も演出をつくる側へ。専用アプリや音楽の知識は必要ありません。

**[デモを開く](https://ai-vdj-devdaycommunity.hapx2yuki.workers.dev/room)** · [操作ガイド](docs/usage.md) · [開発・テスト](docs/development.md)

```text
スマホでQRを読む → ひとこと＋任意の画像を送る → 自分の音楽と映像が大画面に登場
```

## 3ステップで試す

1. **PCで会場を開く**：デモの「ルームを開く」を押し、準備ができたら「再生する」。投稿前から待機セットを楽しめます。
2. **スマホから参加する**：「みんなを招待・受付設定」のQRを読み、「ネオンの猫が踊る」などの言葉を送ります。画像は任意です。
3. **自分の出番を見る**：生成が完了し、順番が来ると、12秒の音楽と映像がセットで流れます。

1人でも投稿して試せます。再生端末はPCのChromeを推奨。生成中も演出は続きますが、完成までの時間は外部サービスの混雑状況により変わります。

## 何がいいのか

[開催要項の4つの評価観点](https://luma.com/OpenAIDevDay2026CommunityHackathonTokyo)に沿って、体験の特徴をまとめています。

| 観点 | AI VDJの特徴 |
| --- | --- |
| **新機能の活用** | OpenAI **Decisions API**を、繰り返し投稿した人が順番を譲る判断に使用。再生を待たせず、みんなの出番を支えます。 |
| **使いやすさ** | QRと短い言葉だけで参加。画像の特徴から詳しい演出指示を自動で作るため、専門的な指示は不要です。 |
| **有用性** | イベントの観客が、その場の演出に参加できます。主催者は投稿の受付・生成・順番管理をまとめて進められます。 |
| **独創性** | 参加者の画像や言葉を共通のDJの世界観へつなぎ、**1投稿＝音楽＋映像の12秒の出番**として一つのショーにします。 |

## Decisions APIで、みんなに出番を回す

通常は投稿順を基本にし、同じ人の連続採用や、ほかの人の一巡前の再採用を調整します。
全件の準備ができている場合は、次のように再生します。後へ回した投稿も残ります。

```text
投稿：A1 → A2 → B1 → C1
再生：A1 → B1 → C1 → A2
```

- **入力**：採用回数と「直前と同じ参加者か」などの数値・真偽値。投稿文・画像・名前は送りません。
- **判断**：`POST /v1/decisions`・`gpt-6-luna`の`choice`で「先頭を再生／順番を譲る」の2択。作品の好みで順位を変えません。
- **体験の維持**：現在のセットの再生中に問い合わせ、回答を固定ルールで確認。遅延・失敗時も同じルールで次を選び、音楽と映像を止めません。

[API呼び出しの実装](cloud/cloudflare/playback-decisions.mjs) · [順番の制御](cloud/cloudflare/playback-queue.mjs) · [設定・検証の詳細](docs/decisions-playback.md)

## 仕組みと詳しい資料

```text
ブラウザで投稿 → Cloudflareで受付・生成管理 → fal.aiで音楽・映像を生成
             → 品質検査・非公開R2へ保存 → 順番を調整 → ブラウザで連続再生
```

画像の特徴解析はCloudflare Workers AI、音楽はStable Audio 3、映像はMiniMax H3 Maxを使用。
画面はReactとaudiocn-ds、再生はWeb Audio APIで構成しています。
